# Skill Catalog

Total: **61 skills**

## Core

- **skill-router** — Use when a request may match multiple installed skills, domains, or workflows and the agent must choose the smallest effective set.
- **intent-clarifier** — Use when a request is ambiguous in a way that materially changes scope, safety, cost, output, or success criteria.
- **task-planning** — Use when a task has multiple dependent steps, nontrivial implementation choices, or meaningful verification requirements.
- **decision-analysis** — Use when choosing among meaningful alternatives with tradeoffs in cost, risk, speed, quality, or reversibility.
- **systems-thinking** — Use when a problem involves interacting components, feedback loops, second-order effects, or local fixes that may create global regressions.
- **root-cause-analysis** — Use when failures recur, symptoms have multiple plausible causes, or a fix would be risky without identifying the underlying mechanism.
- **brainstorming** — Use when generating concepts, features, strategies, names, approaches, or solution directions before implementation is chosen.
- **execution-controller** — Use when carrying out a multi-step plan that requires tool use, checkpoints, state tracking, or recovery from partial failure.
- **verification-before-completion** — Use when the agent is about to claim that work is complete, fixed, deployed, correct, or ready to ship.
- **tool-selection** — Use when multiple tools, connectors, code execution methods, or retrieval paths could accomplish the same task.
- **context-management** — Use when a long-running task spans many messages, artifacts, decisions, or state transitions and important context could be lost or contradicted.
- **workflow-automation** — Use when a repeated manual process can be converted into a reliable recurring, event-driven, or semi-automatic workflow.
- **prompt-engineering** — Use when creating or repairing reusable prompts, system instructions, agent contracts, or tool-using instructions whose behavior must be reliable.
- **agent-design** — Use when designing an AI agent, multi-agent workflow, autonomous loop, or tool-using assistant with persistent responsibilities.
- **skill-authoring** — Use when creating, editing, packaging, or validating reusable Agent Skills in SKILL.md format.

## Research

- **deep-research** — Use when a question requires broad, multi-source investigation, conflicting evidence resolution, or a defensible research synthesis rather than a quick lookup.
- **web-research** — Use when current public information, niche facts, recent changes, or externally verifiable details are needed from the web.
- **fact-checking** — Use when verifying a concrete claim, quote, statistic, date, attribution, causal statement, or disputed factual assertion.
- **source-synthesis** — Use when several documents or sources must be combined into one coherent answer without losing disagreements, provenance, or important nuance.
- **competitive-research** — Use when comparing named competitors, substitute products, market positions, capabilities, pricing, distribution, or strategic differentiation.
- **market-research** — Use when estimating market demand, customer segments, alternatives, size, growth, willingness to pay, or go-to-market conditions.
- **trend-analysis** — Use when assessing whether a topic, product, behavior, technology, or market movement is accelerating, fading, seasonal, or merely receiving temporary attention.
- **evidence-grading** — Use when sources vary materially in quality, claims conflict, or conclusions need an explicit confidence assessment.

- **database-design** — Use when designing or changing relational or document schemas, indexes, constraints, transactions, migrations, or data ownership.
- **frontend-engineering** — Use when building or reviewing web UI components, pages, state flows, forms, accessibility, responsive behavior, or frontend architecture.
- **mobile-first-ui** — Use when a web or app interface must work especially well on phones, touch devices, or small screens.
- **performance-optimization** — Use when latency, throughput, memory, CPU, bundle size, rendering, database cost, or infrastructure efficiency is below target.
- **devops-deployment** — Use when designing or changing CI/CD, environments, containerization, deployment, rollback, secrets, infrastructure automation, or release processes.
- **observability** — Use when designing or improving logs, metrics, traces, alerts, dashboards, or incident diagnostics for a production system.

- **qa-testing** — Use when planning or executing functional, integration, regression, exploratory, compatibility, or release testing beyond unit tests.

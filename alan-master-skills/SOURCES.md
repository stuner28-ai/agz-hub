# Reference sources and provenance

This pack contains **original skill text** written for this bundle. It does not vendor or copy third-party SKILL.md bodies.

Design and compatibility were informed by public Agent Skills conventions and current public ecosystem examples, including:

- OpenAI Plugins: https://github.com/openai/plugins
- OpenAI Skills catalog (deprecated in favor of Plugins): https://github.com/openai/skills
- Agent Skills open specification: https://agentskills.io/
- Public community catalogs such as AgentSkills and Awesome Agent Skills

Third-party repositories can have per-skill licenses. If you later vendor an upstream skill verbatim, preserve its license and attribution.

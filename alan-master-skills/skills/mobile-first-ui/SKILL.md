# Mobile First Ui

## Principle
Design for the constrained viewport and touch interaction first, then expand.

## Workflow
1. Prioritize the primary task and remove nonessential chrome from the first view.
2. Use touch-safe targets, readable typography, sensible keyboard behavior, and reachable controls.
3. Design responsive navigation, tables, forms, dialogs, and dense data explicitly.
4. Account for slow networks, device performance, safe areas, orientation, and virtual keyboards.
5. Test at representative small widths before desktop polish.

## Output contract
- State the result or decision clearly.
- Distinguish verified facts, assumptions, estimates, and unresolved uncertainty when material.
- Include only the detail required to make the output usable.

## Quality gates
- Primary flows work without horizontal scrolling.
- Critical controls remain usable with touch and keyboard.

## Stop conditions
- Stop when the requested outcome and quality gates are satisfied.
- Escalate rather than inventing missing authority, credentials, data, or irreversible permission.

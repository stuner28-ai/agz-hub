# KPI Metrics

## Principle
Use a small metric system that links user value to business outcomes and operational drivers.

## Workflow
1. Define the objective and decision each metric supports.
2. Create a hierarchy: north-star/outcome, input drivers, guardrails, diagnostics.
3. Write exact formulas, event definitions, owner, cadence, and segmentation.
4. Check incentives and gaming risks created by the metric.
5. Remove vanity metrics that do not change decisions.

## Output contract
- State the result or decision clearly.
- Distinguish verified facts, assumptions, estimates, and unresolved uncertainty when material.
- Include only the detail required to make the output usable.

## Quality gates
- Metrics are computable from defined data.
- Guardrails protect against optimizing one outcome by harming another.

## Stop conditions
- Stop when the requested outcome and quality gates are satisfied.
- Escalate rather than inventing missing authority, credentials, data, or irreversible permission.

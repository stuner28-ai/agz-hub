Accesorios de cocina para imprimir en 3D

Organizadores de cajones, soportes para esponjas, ganchos, clips para bolsas y cortantes de galletitas: la cocina tiene muchos objetos chicos que se resuelven bien con una impresora 3D.

Hay que tener cuidado con lo que toca alimentos. Las capas dejan rendijas donde se acumulan restos y bacterias, y ningún filamento común garantiza ser apto para contacto con alimentos una vez impreso. Para cortantes de galletitas de un solo uso puede alcanzar; para recipientes o utensilios de uso repetido, no.

Qué revisar antes de imprimir

  • Cerca del calor, el PLA se deforma: usá PETG o ASA para piezas al lado de la hornalla o el horno.
  • No los laves en el lavavajillas: el agua caliente deforma el PLA y puede ablandar otros materiales.
  • Para piezas que van a estar mojadas, como soportes de esponja, agregá agujeros de drenaje.
  • Medí el cajón o la alacena por dentro antes de imprimir un organizador.
